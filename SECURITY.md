# Security policy

NibKeep will hold passwords and other private data, so security reports are welcome and taken seriously.

## Supported versions

NibKeep is in early development. Only the latest version of its crates on crates.io and the latest code on the main branch are supported.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues, pull requests or discussions.

Report them privately instead, through the repository's private vulnerability reporting: "Report a vulnerability" on the Security tab.

Please include:

- what is affected and what an attacker could do,
- the steps to reproduce the problem,
- any ideas you have for a fix.

The maintainer aims to reply within a week. Once the problem is fixed, it is disclosed publicly, and you are credited unless you prefer otherwise.
